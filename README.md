# Text to Audio Converter

A simple Python project that demonstrates how text can be converted to an audio file using Google's Text-to-Speech (gTTS) library.

## About

This project was created as a way to explore a different application for Python than I normally would. I wanted to do something a little more creative than just the standard practice programs that are so common for learning a new programming language.

This program will take the text that you input, convert it to speech, and then save the result as an MP3 file.

## Features

- Convert text to speech

- Google Text-to-Speech (gTTS)

- Saves as an MP3 Audio File

- Simple & Beginner Friendly

## Technologies

- Python

- gTTS

- Google Text-to-Speech
